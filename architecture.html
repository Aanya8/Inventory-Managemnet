Factory Inventory Management System

Full-stack architecture overview — Vue 3 + FastAPI + In-Memory Data

Tech Stack

Frontend

Vue 3

  • Composition API
  • Vue Router 4.3
  • Axios 1.6 (HTTP)
  • Custom SVG charts
Backend

FastAPI

  • Uvicorn ASGI server
  • Pydantic 2.5 models
  • CORS middleware
  • Port 8001
Data

In-Memory / JSON

  • 7 JSON data files
  • Loaded at startup
  • No database required
  • Filtered in Python
Build

Vite 5.2

  • Dev server :3000
  • HMR for fast reload
  • Proxy to backend
Testing

Pytest

  • FastAPI TestClient
  • Endpoint coverage
  • Filter validation
